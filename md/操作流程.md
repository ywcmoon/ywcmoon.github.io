## 2. 安装 Hugo Extended

### 2.1 先试 winget（失败）

```powershell
winget install --id Hugo.Hugo.Extended -e --accept-source-agreements --accept-package-agreements
```

下载阶段报错：

```
InternetOpenUrl() failed.
0x80072efd : unknown error
```

原因是下载地址指向 github.com，连接超时（`curl -I https://github.com` 同样 20 秒超时）。

### 2.2 改用镜像下载便携版（成功）

测试发现 `gh-proxy.com` 与 `ghfast.top` 可访问，选择前者：

```powershell
# 下载扩展版压缩包（约 22.5 MB）
curl.exe -L -o "$env:TEMP\hugo_extended.zip" "https://gh-proxy.com/https://github.com/gohugoio/hugo/releases/download/v0.169.0/hugo_extended_0.169.0_windows-amd64.zip"

# 解压到用户目录
Expand-Archive -Path "$env:TEMP\hugo_extended.zip" -DestinationPath "$env:LOCALAPPDATA\Programs\hugo" -Force

# 写入用户 PATH（重开终端生效）
$dir = "$env:LOCALAPPDATA\Programs\hugo"
$userPath = [Environment]::GetEnvironmentVariable('Path', 'User')
[Environment]::SetEnvironmentVariable('Path', $userPath.TrimEnd(';') + ';' + $dir, 'User')
```

验证：

```powershell
& "$env:LOCALAPPDATA\Programs\hugo\hugo.exe" version
```

输出：

```
hugo v0.169.0-1da10fc44701c566b1669cdb2d12638f155138bd+extended windows/amd64
```

✅ 检查点：版本号中必须带 `+extended`，否则 PaperMod 的样式构建会失败。

## 3. 初始化站点

目录里已有文档文件，直接建站会报错：

```powershell
hugo new site .
# ERROR ... already exists and is not empty. See --force.
```

加 `--force` 重新执行（只补建缺失骨架，不会删除已有文件）：

```powershell
hugo new site . --force
git init
```

生成骨架：`archetypes/ assets/ content/ data/ i18n/ layouts/ static/ themes/` 和 `hugo.toml`。

## 4. 安装 PaperMod 主题

GitHub 直连同样不可用，先经镜像克隆为 submodule：

```powershell
git submodule add --depth 1 https://gh-proxy.com/https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod
```

克隆完成后把 `.gitmodules` 的 URL 改回官方地址，保证 GitHub Actions 能正常拉取：

```
[submodule "themes/PaperMod"]
	path = themes/PaperMod
	url = https://github.com/adityatelange/hugo-PaperMod.git
```

## 5. 站点配置

删除默认的 `hugo.toml`，新建 `hugo.yaml`：

```yaml
baseURL: "https://ywcmoon.github.io/"
title: "ywcmoon 的博客"
locale: "zh-CN"
defaultContentLanguage: "zh-cn"
theme: "PaperMod"

languages:
  zh-cn:
    label: "简体中文"
    locale: "zh-CN"
    weight: 1

enableRobotsTXT: true
enableEmoji: true
buildDrafts: false
buildFuture: false
buildExpired: false

pagination:
  pagerSize: 10

# 首页额外输出 JSON，供本地搜索（Fuse.js）生成索引
outputs:
  home:
    - HTML
    - RSS
    - JSON

menu:
  main:
    - identifier: posts
      name: 文章
      url: /posts/
      weight: 10
    - identifier: archives
      name: 归档
      url: /archives/
      weight: 20
    - identifier: tags
      name: 标签
      url: /tags/
      weight: 30
    - identifier: search
      name: 搜索
      url: /search/
      weight: 40

params:
  env: production
  author: "ywcmoon"
  description: "记录学习笔记、技术实践与日常思考"

  ShowCodeCopyButtons: true
  ShowReadingTime: true
  ShowShareButtons: true
  ShowToc: true
  TocOpen: false
  ShowBreadCrumbs: true
  ShowPostNavLinks: true
  ShowRssButtonInSectionTermList: true

  defaultTheme: "auto"   # light / dark / auto
  ShowSearch: true

  homeInfoParams:
    Title: "你好，我是 ywcmoon"
    Content: >
      这里记录我的学习笔记、技术实践与日常思考。

  socialIcons:
    - name: github
      url: "https://github.com/ywcmoon"
    - name: rss
      url: "index.xml"
```

三个关键点（踩坑后确认）：

1. `locale` + `defaultContentLanguage` + `languages.zh-cn` 必须配套。Hugo v0.158 起 `LanguageCode` 已弃用，只写它会构建成 EN 站点。
2. `outputs.home` 必须包含 `JSON`，否则不生成 `index.json`，搜索框一直处于禁用状态。
3. `defaultTheme: "auto"` 实现深色模式跟随系统，导航栏另有手动切换按钮。

## 8. 部署配置

### 8.1 `.gitignore`

```
public/
resources/
.hugo_build.lock
.DS_Store
Thumbs.db
build/
.screenshots/
```

### 8.2 `.github/workflows/hugo.yaml`

```yaml
name: Deploy Hugo site to Pages

on:
  push:
    branches:
      - main

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          submodules: recursive

      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: '0.169.0'
          extended: true

      - name: Build
        run: hugo --minify

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./public

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

注意：

- 版本固定为 `0.169.0`，与本地一致；用 `latest` 可能被上游破坏性变更影响。
- `submodules: recursive` 必须保留，否则主题目录为空，构建直接失败。
- `extended: true` 必须保留。

## 9. 问题与解决

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `winget` 安装报 `0x80072efd` | 下载地址指向 github.com，连接超时 | 用 gh-proxy 镜像下载 zip，解压后手动加 PATH |
| `hugo new site .` 报目录非空 | 目录中已有文档文件 | 加 `--force`，只补建骨架 |
| 构建提示 `languageCode` deprecated，语言为 EN | v0.158 起 `LanguageCode` 弃用 | 改用 `locale` + `defaultContentLanguage` + `languages.zh-cn` |
| 搜索框一直禁用 | 缺少 `index.json` | `outputs.home` 中加入 `JSON` |
| 菜单点搜索 404 | `search.md` 被移出 `content/` | 移回 `content/search.md` |
